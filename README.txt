THE AARON APP™ — daily surprise version

This version shows only today's message. The message collection and random-message button have been removed so upcoming messages stay a surprise.

To add or edit messages later, open app.js and edit the quotes array near the top. Each message has text and category fields.

To update GitHub Pages, replace index.html, app.js, and style.css in your repository with these versions. You do not need to change manifest.json.

The daily message is selected by the day of the year and cycles through the messages you have added.
